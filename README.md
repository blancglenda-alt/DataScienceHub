# DataScience Hub — versión lista para GitHub Pages

## Archivos
- `index.html`: página principal.
- `assets/edwin.png`: fotografía recibida del integrante 1.
- `assets/glenda.png`: fotografía recibida de Glenda.
- `assets/placeholder.svg`: marcador para los integrantes 3 y 4.

## Antes de publicar
En `index.html`, busca estas cadenas para completar los dos integrantes restantes:
- `Integrante 3`
- `Integrante 4`
- `Nombre y rol por completar`

Si agregas nuevas fotografías, guárdalas dentro de `assets/` y cambia el valor de `src="assets/placeholder.svg"` por el nombre del archivo correspondiente.

## Publicación en GitHub Pages
1. Crea o abre el repositorio del proyecto.
2. Sube `index.html` y la carpeta `assets` respetando la estructura.
3. En GitHub: **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda. GitHub mostrará la URL pública cuando el despliegue esté disponible.
